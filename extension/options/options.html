Reading Safari…
  1. Keep this app in the Applications folder. Opened from Downloads, it runs as a temporary copy Safari cannot see into; Move to Applications above puts it right.
  2. Open Safari, then Safari → Settings → Extensions, and tick Simpl Courses.
  3. Built without an Apple developer team? Safari lists an unsigned extension only while Safari → Settings → Developer → Allow unsigned extensions is on — and that switch turns itself off every time Safari quits.
