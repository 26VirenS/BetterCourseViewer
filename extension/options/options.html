Canvas sites

BetterCourseViewer works on every *.instructure.com address out of the box. If your school uses its own address (for example canvas.myschool.edu), add it here.

    About

    BetterCourseViewer is a Safari extension that makes Canvas cleaner, faster, and smarter. It runs entirely in your browser: Canvas data is read from your own logged-in session, and page content is only sent to Claude or ChatGPT when you use a smart feature, using the key you provide.

    Safari asks for permission the first time the extension runs on a site. Choose Always Allow on This Website so it keeps working.

    Exports never include your API keys.
