Make a tool

What it asks for, what it works out, and a table or a note if it needs them. It works on the right as you build it. Share it, and once it’s been looked at it shows in Simpl Community and on Simpl’s Tools page.

About it

Colour

Symbol

Inputs

What it asks for: a number, a choice, or a switch (1 when on, 0 when off). Each has a name to use in formulas.

Results

Each is a formula over the inputs and the results above it, worked out in order. The first one shown is the big one.

How formulas work
+ - * / %
add, take away, times, divide, remainder
^
to the power of: v^2, 2^-1
( )
work this out first
< <= > >= == !=
compare: 1 when true, 0 when not
&& || !
and, or, not
c ? a : b
a when c is true, else b: mode == 1 ? v / r : v * r
pi e true false
3.14159…, 2.71828…, 1, 0
sqrt cbrt abs
square root, cube root, size without sign
round(x, 2)
to 2 decimals (round(x): whole); also floor ceil trunc sign
min max
the smallest, the largest of up to 16: max(a, b, c)
ln log log2 exp
natural log, log base 10, base 2, e to the power
sin cos tan
in radians; asin acos atan atan2(y, x); rad(deg), deg(rad)
pow hypot clamp fact
pow(x, y), hypot(x, y), clamp(x, lo, hi), fact(n) (n!)

Something that can’t be worked out, such as dividing by 0, shows “—”. A result can be hidden with Show only when: it shows when that formula is not 0.

Table optional

Facts to look up, shown under the results as they are: a scale, a list of values.

Note optional

Shown at the foot: the formula in words, where it comes from, what to watch for.
