# Verb conjugation data (spec S5 "Verb Conjugations")

Five self-contained JSON files, one per language, with the same top-level keys:

| file | language | pronouns | tenses |
|---|---|---|---|
| `es.json` | Spanish (Spain, with vosotros) | yo, tú, él/ella/usted, nosotros, vosotros, ellos/ellas/ustedes | presente, preterito, imperfecto, futuro, condicional, presenteSubj, imperfectoSubj, imperativo, participio, gerundio |
| `fr.json` | French | je, tu, il/elle/on, nous, vous, ils/elles | present, passeCompose, imparfait, futur, conditionnel, subjonctifPresent, passeSimple, imperatif, participePresent, participePasse |
| `de.json` | German | ich, du, er/sie/es, wir, ihr, sie/Sie | praesens, praeteritum, perfekt, futur1, konjunktiv2, imperativ, partizip2 |
| `it.json` | Italian | io, tu, lui/lei, noi, voi, loro | presente, passatoRemoto, imperfetto, futuro, condizionale, congiuntivoPresente, congiuntivoImperfetto, imperativo, participio, gerundio |
| `pt.json` | Portuguese (European pronouns) | eu, tu, ele/ela/você, nós, vós, eles/elas/vocês | presente, preteritoPerfeito, imperfeito, futuro, condicional, presenteSubj, imperfeitoSubj, imperativo, participio, gerundio |

`check.mjs` (Node ≥ 18, no dependencies) is the **reference engine**: it loads the five files, validates the schema, conjugates every listed verb in every tense and asserts the spec's test vectors plus ~30 more per language. Run `node check.mjs`. Platform ports (Swift, C#) should reproduce its behaviour exactly; the functions `classify`, `conjugate` and `table` are the whole API.

The files are generated by `gen/gen-<lang>.mjs` (`node gen/gen-es.mjs` …; the folder is `gen`, not `build`, which the repository ignores) from compact definitions; edit the generators, not the JSON.

## Schema

```jsonc
{
  "language": "es", "name": "Spanish",
  "pronouns": [6 strings],                 // display labels, in person order 0..5
  "imperativePronouns": [6 strings],       // labels for the imperative row ("—" where no form exists)
  "tenses": [ {"id","name","group", "single"?: true} ],   // teaching order; group ∈ indicativo|subjuntivo|imperativo|condicional|nonfinite
  "groupNames": { group → language's own word },
  "stemKinds": [ {"kind","description"} ],  // documents the stem derivations used by rules.stems
  "rules": {
    "classes":  [ {"id","name","match" (regex on the infinitive),"strip" (chars removed to get the stem),
                   "verbs"? (lexical class: only these), "except"?, "inherits"? (fallback class for endings)} ],
    "endings":  { classId → { tenseId → [6 endings] | "ending" (single tenses) } },
    "stems":    { tenseId → stem spec },     // absent = {"kind":"infinitiveStem"}
    "compose":  { tenseId → [6 items] | {classId|"*" → [6 items]} },   // tense built from other tenses (imperatives)
    "compound": { tenseId → {"aux":"haben|sein","auxTense","with":"partizip2"|"infinitive","auxOf":{aux→[verbs]},"agreement"?} },
    "spelling": [ rule ],                    // orthographic changes, see below
    "accentMap": { vowel → accented vowel }, // for the ´ accent marker
    "raisedStemPersons"?: { tenseId → persons },   // es: where a stemChanging.raisedStem is used
    "separablePrefixes"?: [ … ]              // de
  },
  "irregulars":     { infinitive → { tenseId → [6 forms] | "form", "stemChange": kind|null } },
  "stemChangeKinds": { kind → {"from","to","description","persons": {tenseId → [persons]|"all"}} },
  "stemChanging":   { infinitive → {"kind", "raisedStem"?} },
  "separable":      [ infinitives ],         // de only (empty elsewhere)
  "commonVerbs":    [ ≥ 300 infinitives, most common first ]   // suggestion list
}
```

Conventions:

* A form table is always **6 strings** in pronoun order. Persons that do not exist (1st-person imperative, French 3rd-person imperative, impersonal verbs like *falloir*, *gelingen*) hold the placeholder `"—"` (U+2014), never an empty string.
* Tenses with `"single": true` (participles, gerund) hold **one string**.
* Forms never include the pronoun. French `je` must be elided by the UI before a vowel or mute h (`j'ai`, `j'habite`, `que j'aie`).
* An `irregulars` entry lists only the tenses whose forms differ from what the rules would produce (plus **all** tenses for the 15 most common verbs). Any tense missing from an entry is produced by the rules.
* `stemChange` inside an irregular entry is informational (the kind, or `null`).

### Stem specs (`rules.stems`) and the `stemKinds` list

| kind | meaning |
|---|---|
| `infinitiveStem` | infinitive minus the class's `strip` characters (hablar → habl). Default. Optional `suffix` (string or `{classId: suffix}`) is appended **after** spelling rules: French futur `achet → achèt + er + ai`, Italian futuro `cerc → cerch + er + ò`. |
| `infinitive` | the whole infinitive (es/pt futuro: hablar + é). |
| `infinitiveMinusR` | infinitive without the final r (es vosotros imperative: habla + d). |
| `form` | `{tense, person, strip}`: take that already-conjugated form of the same verb (irregular-aware) and strip a suffix. es imperfectoSubj = preterito[5] minus `ron` (tuvieron → tuvie); pt imperfeitoSubj = preteritoPerfeito[5] minus `ram`. |

A spec may be a list of specs each with `"persons"`, or `{"byClass": {classId: spec, "*": spec}}`.

**Accent marker**: an ending beginning with `´` (U+00B4) accents the last vowel of the stem using `rules.accentMap`, then the rest of the ending is appended: `tuvie + ´ramos → tuviéramos`, pt `come + ´ssemos → comêssemos`.

**Ending template**: an ending containing `%` wraps the stem: German Partizip II `ge%t` → `ge + lern + t`.

### Spelling rules

```jsonc
{ "id": "car->qu", "when": "plain-English condition",
  "classes"?: [...], "verbs"?: [...], "except"?: [...],
  "match"?: regex on the stem, "verbMatch"?: regex on the infinitive, "endingMatch"?: regex on the ending,
  "tenses": { tenseId: [persons] | "all" },
  "do": { "stem"?: {"from": regex, "to"}, "ending"?: {"from": regex, "to"} } }
```

All conditions are tested against the stem/ending **as they were before any spelling rule ran** (rules never cascade), then the `do` replacements are applied in file order.

Included: es `-car/-gar/-zar/-guar`, `-cer/-cir → zc / z`, `-ger/-gir → j`, `-guir → g`, `-uir → uy`, `i → y` and `i → í` after vowel stems (leyó, leído); fr `-cer → ç`, `-ger → ge`, `-yer → i`, `e → è` (acheter type, verb list), `é → è` (préférer, boot only), `-eler/-eter` doubling (except list); de e-insertion (arbeitest, arbeitete, gearbeitet, arbeite!), s/ß/z/x stems (du heißt), `-eln` (ich lächle, lächle!), `-ern` imperative, no `ge-` for inseparable prefixes and `-ieren`; it `-care/-gare → h`, `-iare` i-drop, `-ciare/-giare` futuro i-drop; pt `-car/-gar/-çar`, `-cer/-cir → ç`, `-ger/-gir → j`, `-guer/-guir → g`, `-uir → uis/ui`, accented `í` after vowel stems (possuímos, caía, saído).

### Stem changes (`stemChangeKinds`, `stemChanging`)

`stemChanging[verb] = {kind, raisedStem?}`. The kind says which letters change (`from` → `to`, replacing the **last** occurrence in the stem) and in which tense/persons. Spanish e>ie / o>ue / u>ue / e>i / i>ie / i>í / u>ú apply in the boot persons (0,1,2,5) of presente and presente de subjuntivo; `raisedStem` (sint-, durm-, pid-) is used instead wherever `rules.raisedStemPersons` says (presenteSubj nosotros/vosotros, preterito 3rd persons, gerundio). Portuguese kinds: e>i and o>u (eu + whole conjuntivo), u>o (tu/ele/eles), e>ei / i>ei (-ear, odiar). French and Italian use no stem-change kinds (Italian's `-isc-` is a lexical class; French alternations are spelling rules or explicit irregulars). Stem changes apply only to `infinitiveStem` stems, so a tense derived from another form (`form` kind) inherits the change automatically.

### Compound and composed tenses

* `compound` (fr passé composé; de Perfekt, Futur I, Konjunktiv II): `aux` present (or `auxTense`) + participle / infinitive. The auxiliary is the first of `aux` unless the verb (or, for a German separable verb, its base) is in `auxOf[other]`. `agreement[aux]` is 6 suffixes appended to the participle (French être: `allé, allés` – masculine forms; feminine not shown). German Konjunktiv II is `würde + infinitive` by default; sein/haben/werden, the modals, wissen and common strong verbs carry their own forms in `irregulars` (wäre, hätte, käme, ginge, …).
* `compose` (imperatives): each of the 6 items is `{"literal"}`, `{"form": tense, "person", "stripIf"?: regex → drop last char}` or `{"stem": kind, "ending"}` (goes through spelling rules). Spanish: tú = presente[2], usted/nosotros/ustedes = subjunctive, vosotros = infinitive − r + d. Italian: per class (-are tu = presente[2], others presente[1]; Lei/Loro = congiuntivo). Portuguese: vós = presente[4] minus s. French: tu = present[1] (minus s when it ends in -es), nous/vous = present. German: du = stem (+e by rule), ihr = Präsens, wir/Sie = infinitive + " wir"/" Sie".

### German separable verbs

`separable` lists the verbs; `rules.separablePrefixes` the prefixes (longest match wins). Finite tenses conjugate the base verb and append the prefix (`fange an`, `fing an`, `fang an!`, `fangen Sie an`); Partizip II = prefix + base participle (`angefangen`, `vorbereitet`); compound tenses use the whole infinitive (`werde anfangen`, `würde anfangen`) and the aux of the base unless the separable verb itself is in the sein list (`bin eingeschlafen`). Inseparable derivatives (verstehen, bekommen, unternehmen …) are plain `irregulars` entries.

## How the engine applies the data (normative order)

```
conjugate(verb, tense):
  1. irregulars[verb][tense] exists          → return it            (irregular wins, always)
  2. tense is in rules.compound              → aux forms + " " + participle/infinitive (+ agreement)
  3. verb is in separable (de)               → conjugate base, append prefix / prefix the participle
  4. tense is in rules.compose               → build each person from other tenses (recursively via step 1)
  5. regular:
       class  = first rules.classes entry whose regex matches (and verb list / except agree)
       for each person i:
         stem    = rules.stems[tense] kind   (default infinitiveStem)
         stem    = stem change (stemChanging + stemChangeKinds / raisedStem)   – infinitiveStem only
         (stem, ending) = spelling rules whose tense/person/class/match conditions hold
         stem   += stem spec suffix (futur -er-, …)
         if ending starts with ´: accent last vowel of stem (accentMap), drop the marker
         form    = ending contains % ? ending with % → stem : stem + ending
```

So the precedence is **rules → spelling → stem change → irregular override**, where the irregular entry replaces the whole tense. "Highlight irregular forms": a cell is irregular when the final form differs from the purely regular computation (`conjugate(verb, tense, {ignoreIrregular: verb})`); `table(data, verb)` in `check.mjs` returns both. Tenses derived with a `form` stem stay regular-looking if their source is regular, and are flagged when the source was irregular (tuviera).

## Worked examples

### Spanish
1. **hablar · presente** – class `ar`, stem `habl`, no stem change, no spelling rule → `hablo, hablas, habla, hablamos, habláis, hablan`. Imperativo composed: `—, habla (presente[2]), hable (subj[2]), hablemos, hablad (habla + d), hablen`.
2. **empezar · presente de subjuntivo** – class `ar`, stem `empez`; stemChanging e>ie in persons 0,1,2,5 → `empiez`; spelling `zar->c` (all persons) → `empiec` / `empec` → `empiece, empieces, empiece, empecemos, empecéis, empiecen`.
3. **tener · imperfecto de subjuntivo** – not explicit? It is (tener is a top-15 verb), but it would also derive: stem kind `form` = preterito[5] `tuvieron` (irregular) minus `ron` = `tuvie`; endings `ra, ras, ra, ´ramos, rais, ran` → `tuviera … tuviéramos …`. Regular computation gives `teniera`, so every cell is tinted.

### French
1. **manger · présent / imparfait** – class `er`, stem `mang`; rule `ger->ge` fires for present[3] and imparfait[0,1,2,5] → `mangeons`, `mangeais, mangeais, mangeait, mangions, mangiez, mangeaient`.
2. **acheter · futur** – stem `achet`; rule `e->è` (verb list) for futur all → `achèt`; suffix `er` → `achèter` + `ai` → `achèterai`. **appeler** instead hits the doubling rule → `appellerai`.
3. **aller · passé composé** – compound: aux `être` (aller is in `auxOf.être`), être.present + `allé` + agreement `s` for persons 3–5 → `suis allé, es allé, est allé, sommes allés, êtes allés, sont allés`. **prévenir** derives from venir but is not in the être list → `ai prévenu`.

### German
1. **arbeiten · Präsens / Präteritum / Partizip II** – class `en`, stem `arbeit`; e-insertion (stem ends in t) → `arbeite, arbeitest, arbeitet, arbeiten, arbeitet, arbeiten`; `arbeitete …`; `ge%t` + `t→et` → `gearbeitet`; Imperativ du `arbeite`.
2. **anfangen · Präsens / Perfekt** – in `separable`, prefix `an`, base `fangen` (irregular: fange, fängst, fängt …) → `fange an, fängst an, fängt an, fangen an, fangt an, fangen an`; Perfekt: aux haben (neither anfangen nor fangen in the sein list) + `an` + `gefangen` → `habe angefangen`.
3. **lernen · Konjunktiv II / Futur I** – compound: werden.konjunktiv2 (explicit `würde …`) + infinitive → `würde lernen …`; `werde lernen …`. **kommen** has an explicit konjunktiv2 → `käme`, so irregular wins.

### Italian
1. **cercare · presente / futuro** – class `are`, stem `cerc`; rule `care/gare->h` for presente[1,3], congiuntivo all, futuro/condizionale all → `cerco, cerchi, cerca, cerchiamo, cercate, cercano`; `cerch + er + ò` → `cercherò`.
2. **capire · presente** – lexical class `isc` (listed in `classes[0].verbs`), endings `isco, isci, isce, iamo, ite, iscono`; passato remoto inherits `ire` → `capii, capisti, capì …`. Imperativo (class `*`): `—, capisci (presente[1]), capisca (cong[2]), capiamo, capite, capiscano`.
3. **prendere · passato remoto** – explicit in irregulars only for passatoRemoto and participio: `presi, prendesti, prese, prendemmo, prendeste, presero`, `preso`; everything else (presente `prendo …`, futuro `prenderò`) comes from the `ere` rules.

### Portuguese
1. **ficar · pretérito / conjuntivo** – class `ar`, stem `fic`; `car->qu` for preteritoPerfeito[0] and presenteSubj all → `fiquei, ficaste, ficou, ficámos, ficastes, ficaram` (Brazil: `ficamos`), `fique, fiques, fique, fiquemos, fiqueis, fiquem`.
2. **dormir · presente / conjuntivo** – stemChanging o>u in presente[0] and presenteSubj all → `durmo, dormes, dorme, dormimos, dormis, dormem`; `durma, durmas, durma, durmamos, durmais, durmam`. Imperativo: `—, dorme, durma, durmamos, dormi (dormis − s), durmam`.
3. **ter · imperfeito do conjuntivo** – explicit (top-15): `tivesse … tivéssemos` (acute é, unlike regular `comêssemos`). Had it not been explicit, the engine would derive from preteritoPerfeito[5] `tiveram` minus `ram` → `tive + sse`, `tivê + ssemos` – which is why strong preterites carry their own imperfeitoSubj.

## Notes / choices to be aware of

* Spanish: *vosotros* forms throughout; accentless monosyllables per RAE 2010 (`rio`, `frio`, `hui`), but `sonrió`. Negative imperatives are not included.
* French: only masculine participle agreement is shown with être; reflexive verbs are not covered; `-ayer` verbs are given with `i` (`paie`), `y` is also accepted; `é→è` is not applied in the futur (`préférerai`, traditional spelling); defective *falloir* / *pleuvoir* show `—` except the 3rd person.
* German: Konjunktiv II is the `würde` form for regular verbs and for strong verbs without a listed form (helfen → würde helfen; hülfe is archaic). Präteritum 2nd person after s/ß/z uses the long form (`du lasest`, `du aßest`); `wärst/wärt` for sein, `kämest/kämet` for other strong verbs. `wissen` and the modals have no imperative (`—`). Duden short forms (`last` for `lasest`) are not listed.
* Italian: regular `-ere` passato remoto uses the `-ei/-é/-erono` set (`credei`); `-etti/-ette/-ettero` is also correct. `dovere` is given with `dovetti`. `tu` imperatives `fai / vai / dai / stai` (the apostrophe forms `fa'`, `va'` are equally valid); `dire` uses `di'`.
* Portuguese: European spelling and pronouns (`vós` row, `-ámos` in the pretérito of -ar verbs; Brazil writes `-amos`, everything else identical). Double participles: `pago / gasto / ganho` are given (the regular `pagado / gastado / ganhado` also exist with *ter* in Brazil). `você` row uses the 3rd-person subjunctive form.
* `commonVerbs` is a frequency-ish ordering by hand, not a corpus count.
