**Liquid Glass on Windows — candidates to try.** A test build for evaluation only; it is not Simpl, and Simpl's own updates never offer it.

- **LiquidGlass-liquidImgui-win64.zip** — the closest copy found: a native Direct3D 11 app that refracts the live desktop behind its window, with springy widgets, a dock, a command palette (Ctrl+K) and live material tuning. MIT licence ([charlie-x/liquidImgui](https://github.com/charlie-x/liquidImgui)).
- **LiquidGlass-AuroraGlass-win64.zip** (if present) — a younger Direct3D 11 SDK; its interactive demo drags glass over its own content, with a glass button, toggle and slider. Apache-2.0 ([VeiQiuLab/AuroraGlass](https://github.com/VeiQiuLab/AuroraGlass)).

Unzip, run the exe (keep its folders beside it). Not code-signed: on "Windows protected your PC", choose **More info → Run anyway**. Each zip has a README-FIRST.txt.
