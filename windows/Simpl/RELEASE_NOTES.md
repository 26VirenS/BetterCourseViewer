**Simpl for Windows — an early preview.** A test build for evaluation, not a release: Simpl's own updates never offer it.

**Simpl-Windows-x64.zip** — unzip anywhere and run **Simpl.exe** (everything it needs is in the folder; it uses Microsoft Edge WebView2, which Windows 10 and 11 already have). Not code-signed: on "Windows protected your PC", choose **More info → Run anyway**.

What is in it so far:

- **Simpl's glass everywhere**: the window is drawn by Simpl's own renderer (Direct3D 11) with the glass chosen in the showcase — the frost, the bending edges, the rim of light, soft squircle cards and round bars;
- **your school**: find it by name (or type its address), then sign in as on the web; the app's own screens go over it once you are in;
- **the sidebar**: Dashboard, To Do, Calendar, Grades, Notifications, the Inbox, Tools, your courses (with their sections) and groups;
- **the toolbar**: Back and Forward, Refresh, the screen's title, Search;
- **the Dashboard**: the greeting, the six counters, Cards · List · Activity (tick work off in the List), today's work and the week's load.

The other screens open as the school's own page for now; they come over from the Mac one by one.
